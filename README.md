This is to be a Linux file manager similar to PCgeos. No X11, just a single file made in golang.
Right click menu. Mouse and keyboard operated. Multiple drag-able windows with file path box. 

keyboard shortcuts:
Super+e - opens a new file window
Super+k - closes file window
Super+q - prompt to quit program
Super+left - 
ctrl+x - cut
ctrl+c - copy
ctrl+v - paste
ctrl+left - fit left side screen
ctrl+right - fit right side screen
ctrl+up - collapse window to title
ctrl+down - expand window from title
arrows - navigation
alt-tab - jump between windows, show text list using prev/current folder
backspace - up folder
pgup/pgdn/home/end - navigation as per key
